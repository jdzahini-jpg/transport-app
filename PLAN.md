# 📋 Plan du projet Transport App

## 🎯 Vision

Garantir au voyageur togolais qu'il partira à l'heure qu'il a choisie, sans attendre que le véhicule se remplisse.

## 🚀 V1 — Semaine 1-4 (en cours)

**Objectif** : Prouver la demande avec 5-10 chauffeurs et 50+ voyageurs à Lomé

### Fonctionnalités
- [x] Structure du projet
- [ ] Inscription / connexion
- [ ] Publication de trajets par les chauffeurs
- [ ] Demande de réservation par les voyageurs
- [ ] Matching semi-automatique (proposition d'heure)
- [ ] Génération de QR code
- [ ] Scan du QR code à l'embarquement
- [ ] Dashboard admin

### Ce que je fais à la main
- Valider les cas ambigus
- Gérer les annulations
- Contacter les chauffeurs

## 📈 V2 — Mois 2-3

**Objectif** : Automatiser le matching

- [ ] Algorithme de matching automatique

- [ ] Système de notation
- [ ] Tableau de bord chauffeur

## 🏆 V3 — Mois 6-12

**Objectif** : Couvrir tout le Togo

## 💰 Modèle économique

- Commission : 10% sur chaque réservation
- Frais de réservation payés par le voyageur

- Next.js + React
- Supabase (base de données)
- Vercel (hébergement)
- Mobile Money (à venir)
