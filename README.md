# 🚐 Transport App

Plateforme de réservation de transport au Togo.

## 🎯 Vision

Garantir au voyageur togolais qu'il partira à l'heure qu'il a choisie, sans attendre que le véhicule se remplisse.

## 📱 Comment ça marche

1. Le voyageur indique sa destination et une fourchette horaire
2. Le système trouve un véhicule compatible
3. Le voyageur reçoit un QR code de réservation
4. À l'embarquement, le chauffeur scanne le QR code

## 🗺️ Roadmap

- **V1** (en cours) : Réservation de places, matching semi-automatique
- **V2** : Matching automatique, paiement intégré
- **V3** : Bus interurbains, app mobile, multi-villes

## 🛠️ Stack technique

- **Frontend** : Next.js
- **Base de données** : Supabase
- **Hébergement** : Vercel
- **Paiement** : Mobile Money (à venir)
